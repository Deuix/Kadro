# Kadro — iOS Product Prompt & Sprint Plan

## 0. One-line product definition

**Kadro** is a native iOS AI companion for creators, experts, and small businesses that turns raw ideas into **publish-ready Instagram posts, carousels, stories, and TikTok/Reels scripts** with strong UX, built-in brand memory, and simple content planning.

This is **not** just an AI writer.  
This is a **mobile content operating system** focused on:

- capturing ideas fast
- transforming one idea into multiple formats
- generating modern carousel structure and design
- keeping a consistent brand voice
- helping users publish more with less friction

---

## 1. Project clarity: what exactly are we building?

### Core promise

A user should be able to go from:

**idea / voice note / rough thought**  
to  
**ready content package**

in a few minutes, without needing a designer or SMM for routine work.

### What Kadro is
- an iPhone-first content creation companion
- an AI-assisted workflow tool
- a guided content studio for non-experts
- a brand-aware post and carousel generator
- a lightweight planner for publishing content

### What Kadro is not
- not a generic chat app with one text box
- not a full desktop-grade Canva replacement
- not a complex social media agency suite
- not an analytics-heavy enterprise dashboard
- not a “write anything” AI tool with vague value

### Product positioning

**Kadro helps users turn thoughts into ready social content with speed, taste, and structure.**

### Main JTBD
Users hire Kadro to:
1. quickly capture ideas when inspiration appears
2. turn one raw thought into usable social content
3. avoid blank-page syndrome
4. keep content on-brand
5. create polished carousels without manual design work
6. adapt one idea into Instagram + TikTok formats
7. keep a simple publishing rhythm

## 3. Product principles

### 1. Workflow-first, not chat-first
AI is an assistant layer, not the main UI pattern.  
The product should guide users through creation steps.

### 2. One main action per screen
Every important screen must have one obvious primary CTA.

### 3. Structured output, not AI text walls
Generated results must be broken into clear sections:
- hook
- body
- CTA
- slide structure
- caption
- script beats

### 4. Control without overload
Users should feel in control, but without seeing too many settings.

### 5. Human language only
No jargon like:
- Generate asset
- Repurpose unit
- Optimize narrative

Use:
- Create carousel
- Make the hook stronger
- Turn into TikTok
- Shorten text

### 6. Preview everywhere
Users should constantly see what they are creating.

### 7. Brand-aware by default
The product must remember tone, writing rules, and visual preferences.

---

## 4. Target users

### Primary users
- solo creators
- coaches / consultants / experts
- small business owners
- founders building personal brands

### Secondary users
- content managers
- SMM freelancers
- creator assistants

### Beginner reality
Most users are not designers and not great at content structuring.  
The product must remove fear and friction, not expose complexity.

## 5. Core user outcomes

A successful Kadro session gives the user one of these outcomes:

- a ready Instagram caption
- a ready carousel draft
- a TikTok/Reels script
- a full content pack from one idea
- a scheduled draft for later publication

The user should leave with something concrete, not just “inspiration”.

## 18. Recommended engineering/product notes

### Native direction
Build **native iOS first**, not a web app wrapped inside.

### Why
- better mobile UX
- better motion
- better voice note flow
- better perceived quality
- stronger chance of editorial-level polish

### Product strategy note
Even though web may still be useful later, Kadro on iOS should be designed as a truly native experience, not a reduced dashboard.
